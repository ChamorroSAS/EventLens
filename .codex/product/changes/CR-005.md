## Decision / gates
La solicitud autoriza el correctivo incremental. Se preservan DECISIONS y baseline aceptado. El bootstrap inicial no requiere un nuevo proveedor de identidad ni reabre un bootstrap consumido. Una transacción SQL corta une las escrituras existentes; ninguna llamada a una autoridad externa se incluye dentro de esa transacción.

**BLOCKED — recuperación administrativa excepcional sobre base consumida:** los contratos actuales no definen una autorización operacional externa verificable para reemitir credenciales sin un administrador autenticado. El método de registro de credencial no constituye autorización. No se inventará una excepción ni una autoridad en memoria. Requiere contrato adicional de autorización, revisión/epoch/watermark y PREPARE→SQL→ACK con adapter durable independiente. Esto no bloquea aislamiento ni bootstrap inicial local.
